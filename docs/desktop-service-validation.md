# Windows / Ubuntu 验证状态

桌面客户端使用原生窗口、Avalonia 控件和系统托盘，与 Mac 共用品牌、五种语言和价格数据。Windows 使用侧栏，Ubuntu 使用顶部导航。代码检查、模拟验证与真实账户验收是不同阶段；本轮按用户要求进行模拟验证，真实账户由用户安装后检查。

## 已实现的日常操作

- 首页进入详情，详情的用量始终展开；用量和设置共用连接状态、刷新入口。
- 首页“更多”直接进入显示与外观、用量历史、通用设置、关于；返回保留来源，常用入口不在通用设置重复出现。
- 服务管理负责启用、禁用、排序；API Key 只在对应服务详情编辑，并提供官方获取入口。刷新保留未提交的输入。
- 备注的折叠按钮在右侧，展开状态与草稿在刷新中保留。
- 显示内容采用“内容项 / 状态 / 托盘”表格；状态为首页、仅详情、隐藏，至少保留一项首页内容。支持调整顺序和恢复显示默认值；备注位于其后。托盘每个服务最多选择两项，选满后禁用其他选项并显示原因。
- 浅色、深色、跟随系统、已用/剩余、紧凑布局、隐藏数值；隐私模式同时遮挡金额、进度条和托盘数值。
- 通用设置集中刷新间隔、语言和登录启动；通知、隐私与高级设置从该页进入并返回。通知与 Mac 一样分为即将耗尽、接近上限、将会耗尽，首次读取不提醒，投递失败允许重试。显示与外观按用量显示、应用界面、系统托盘分组，支持减少动画。
- 用量历史包含今日、昨日、30 天的 token/费用汇总和每日明细，可切换费用、每百万 token 费用和 token 总量。费用按模型估算，不等于订阅账单；无法计价时显示不完整，不冒充零费用。
- 主用量成功后，附加套餐/重置卡接口单独限时；附加请求超时或限流不会抹掉主用量。用户取消仍会停止整个刷新。
- 多配置目录账号、Codex Swap 和 Claude Swap 文件凭据的只读读取；账号自身 CLI 登录文件不因切换显示而被替换。

## 服务与模拟验证

| 服务 | 登录来源与用量 | 本轮验证 |
| --- | --- | --- |
| Claude | CLI 文件、多配置目录、Claude Swap；会话、每周、模型额度、额外用量、日志 token/估算费用 | 文件、HTTP 模拟、计数去重、价格与错误响应 |
| Codex | CLI 文件、附加配置目录、Codex Swap；会话、每周、积分、重置额度到期信息、日志 token/估算费用 | 文件、HTTP 模拟、日志边界、积分与错误响应 |
| Cursor | 桌面 SQLite 登录、远端额度及 token 导出 | 数据库、模拟请求、导出解析、历史隔离 |
| Amp | 原生 CLI 或 Windows npm 的 Node 入口、现有环境/文件凭据；Agent、Orb、余额 | 真正启动模拟 CLI，覆盖标准输出、标准错误、失败退出以及数值解析 |
| Antigravity | Windows Credential Manager / Ubuntu Secret Service 的 gemini:antigravity 登录；Google OAuth 续期、Cloud Code 四类额度 | 凭据解码、模拟请求、配额解析、拒绝/限流/异常数据 |
| Ollama | 已有 OpenSSH Ed25519 登录密钥；签名请求获取云用量、费用和账户计划 | 密钥损坏、独立验签、实际 HTTP URI 与签名一致性、响应映射 |
| Copilot | 编辑器配置、GitHub CLI 文件及系统凭据；个人配额和有权限的组织账单 | 文件、HTTP 模拟、无限额度、组织计价与席位费排除 |
| Devin | CLI 文件、桌面数据库、文件中配置的 HTTPS 企业服务器；日/周额度及额外余额 | 文件、模拟请求、缺失字段、HTTPS 地址限制 |
| OpenCode | CLI 本地登录文件；订阅用量接口 | 文件、模拟请求、缺失凭据和错误响应 |
| Grok | CLI 登录、令牌续期；周额度、完成的会话 token/费用 | 模拟续期与保存、保留其他账号、日志去重与费用单位 |
| DeepSeek、Kimi、MiniMax、OpenRouter、SiliconFlow、Z.ai | 服务详情保存/移除 API Key，调用各自官方额度接口 | 六项均验证密钥路由、成功映射、401/403、429、5xx 和异常响应 |

API 密钥不进入偏好或历史。Windows 使用当前用户 DPAPI；Ubuntu 使用仅当前用户可访问的文件。Grok 续期与 Mac 一样需要保存新的 CLI 令牌，写入时保留其他账号与未知字段，并在检测到文件变化时拒绝覆盖。

新增 BouncyCastle.Cryptography 用于跨平台 Ed25519 签名；.NET 内置 API 不提供与此格式匹配的统一实现。版本与依赖锁定，许可证随安装包携带。Avalonia.Headless 仅用于界面测试，不进入产品依赖。

## 平台适配与验收边界

- macOS 专属的 iCloud 和透明度设置不进入 Windows / Ubuntu 的设置菜单，也不列为跨平台待补功能。Windows / Ubuntu 使用系统托盘与原生窗口控件。
- Antigravity 当前走系统凭据和 Cloud Code；尚未移植 Mac 的本地语言服务器/旧数据库兜底。
- 多账号不包含 Mac 的全部 pi/钥匙串来源、独立账号隐藏/删除和每个账号的历史管理；当前设置与历史仍以服务为单位。
- 价格来自同一份内置快照，支持长上下文、快速模式和一小时缓存；桌面版尚未移植价格表在线刷新和手动回退模型设置。
- 系统通知实际投递、开机启动、托盘恢复、不同 DPI、安装升级卸载和真实付费账户，仍需在 Windows/Ubuntu 真机验收。系统策略可能阻止通知或隐藏托盘。
- Windows 安装包未签名。Ubuntu 包面向 x64，安装依赖包含 libsecret-tools 和 libnotify-bin。

因此不能把本轮模拟检查通过表述为“所有功能与 Mac 完全一致”或“所有真实服务均已验证”。

## 界面验收范围

浅色与深色均检查首页、服务管理、详情用量/设置、显示与外观、通用设置、通知、隐私与高级设置、用量历史和关于。自动化覆盖返回来源、嵌套返回、凭据入口、最后一项首页内容保护、托盘两项上限、详情完整展开及隐私遮挡。全局快捷键、按账号独立设置、Codex 费用模型选择仍未与 Mac 完全一致，不能把这一轮称为全部设置已完成对齐。
