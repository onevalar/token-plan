# 主页用量样式实验室

这是供选择的独立中文原型，不是已经采用的产品界面。只探索主页中每个账号的额度、余量、重置与余额，不重复上一轮历史总量统计。上一轮 `total-studies` 的代码和选择记录保留，正式应用没有导入本目录，也没有改动正式界面、真实账号、设置、依赖或翻译表。

## 怎么比较

开发服务下的 `/explorations/home-usage-studies/` 提供五个方向，各三种结构，共 15 款新样式。底部切换方向，左侧选择该方向的三款结构；面板下方的左右按钮可以依次走完全部方案。

按 1–5 或左右键切换方向；滑块、输入框和下拉选择中的键盘操作优先服务当前控件。当前方案、主题、宽度、场景及已用／剩余模式会写入网址，刷新后保留；模拟滑块在刷新后回到固定示例。

| 方向 | 三种结构 | 适合比较的问题 | 代价 |
| --- | --- | --- | --- |
| A 刻盘 | 精密双针、侧缘刻盘、主次仪表 | 指针的位置感能否帮助快速判断额度 | 比文字列表占高度，精确读数仍靠数字 |
| B 电量 | 点阵电芯、斜切栅格、分仓电池 | 是否更喜欢分段储量而不是一根横条 | 细小差异仍需数字；分段不代表请求次数 |
| C 周期 | 双层跑道、并行周期、重置日晷 | 额度和重置时间一起看是否更有用 | 跑道最占空间；双通道必须保留图例 |
| D 游标 | 水平游标、边缘标尺、折返刻度 | 小窗口里能否用更少色块阅读更多账号 | 折返标尺第一次需要读端点与方向 |
| E 版式 | 额度票据、对开余量、数字书脊 | 以数字和对齐为主是否更适合每天打开 | 图形记忆点较弱；双面额度增加信息量 |

每款方案旁都有具体试法、取舍及参考元素。参考图的仪表、分段电量、设备列表、轨道和财务排版用于设计发散，不代表 TokenPlan 提供图中的电力、赛车或财务功能。

“对照现有样式”直接使用正式 `HomeMetrics`，七种现有样式原样切换，不把新原型的读数格式或图形改动混入基线。基线不接受新原型的单色和字号调节。

## 可以实际操作的内容

- 切换已用／剩余、服务色／单色、浅色／深色，比较 390、460、560px 面板；空间不足时展示实宽，不把缩小后的面板称为所选宽度。
- 调节数字字号、留白和圆角。小型刻盘和列表按各自比例响应字号，不强迫全部数字一样大；改变的是 CSS 变量，不让数据与账号跟随这些外观参数重新生成。
- 调节第一个 Claude 示例的两项额度和周期进度；其他账号保持不动。固定边界场景禁用数据滑块，说明原因。
- 点击额度名称查看准确读数和重置时刻；Escape 或关闭按钮返回原标签，并让标签回到可见位置。
- A3 的上下键只移动选项焦点，Enter / Space 才切换放大的额度；其他额度始终保留。
- 收藏候选、逐款记笔记、复制或下载记录。复制被浏览器拒绝时仍可手动复制文本。
- 加载、失败、空状态都有可以恢复到示例数据的真实按钮，不会无限等待。

## 数据边界

全部账号与数值均为虚构。固定示例时刻为 2026-10-28 08:00 UTC，不读取本机凭据或服务商账单。

- 常规示例：Claude 38% / 82%，Codex 18% / 29%，Cursor 67.4% 及 $3.25，DeepSeek ¥126.85。
- 每项额度独立，不把 Session 和 Weekly 相加、平均或合为同一个电池。金额仍按金额显示，且保留原有指标顺序。
- 已用／剩余只在输入边界转换一次。112% 已用对应 −12% 剩余，文字保留超额，只有图形停在边界。
- 原始已用达到 80% 才警告，切到剩余模式不改变危险判断。单色模式也保留危险文字和颜色。
- 缺失、过期旧读数和真实零不混淆：未知没有数值型 meter，也没有指针或已填充的假读数。
- 点阵、电芯最后一格允许部分填充，不把 0.4% 四舍五入成零格；38% 电池是 3.8 格，而不是四整格。
- 周期只有在有效时间窗口内才显示进度；未开始、已到期、未知、无法成立的窗口不画假时钟。时间不是消耗预测；切换已用／剩余也不反转时间。
- 未调时间时，Session 已过 40%，Weekly 约 40.5%。主动拖动时间滑块后，两项才使用同一比例。100% 表示到期待刷新，不假设已经续期。
- E2 同时展示已用和剩余，切换模式只改变重点；底边的已用占比不会随强调方向而悄悄反转。
- D3 是同一根折返标尺，位置计算包含弯道长度，50% 在折返点。

11 种场景包括日常、单账号、0/100/超额/小数、79.6/80 警戒边界、缺失与旧读数、重置边界、三项与同周期／混排金额、40 项长名称，以及加载、失败、空状态。

## 留下决定

记录仅保存在当前浏览器的 `tokenplan-home-usage-studies-review-v1`，与上一轮总量统计的键分开。导出包含当前方案、比较条件、外观参数、候选和意见；固定场景不会错误地把未启用的数据滑块值列为当前读数。不会自动把意见发给其他人或写入产品设置。

用户尚未选定。可以跨方向组合，例如某款刻盘与另一款重置区，但组合后的实际尺寸仍需下一轮确认；收藏不等于批准接入产品。

## 技术与检查

使用项目现有的 React 19、CSS、Geist / Inter 字体和 Arc 基础变量。复用 Arc Button、Select、Switch；本目录的 Slider、SegmentedControl 来自 Arc 官方免费注册表，保留 MIT 授权，没有新增依赖。SegmentedControl 保持官方源码；Slider 只增加本地 `animateValue` 选项，本页关闭数字滚动，避免拖动时控件读数短暂落后于面板，其他交互保留。额度图形在已有 Gauge / Usage Meter 的固定分母语义上探索，不以来源构成图冒充额度。

运行类型检查：

```sh
npx --no-install tsc --noEmit -p explorations/home-usage-studies/tsconfig.json
```

正式项目的单元检查仍用 `npm test`。本轮另外用临时浏览器脚本验证所有样式的数值、状态、尺寸和真实输入，不把设计原型测试加入永久产品测试套件。

Arc 检查已覆盖：

- [x] 语义颜色、400/500 字重、可对齐的数字、非纯颜色警戒、真实服务标志。
- [x] Arc 组件使用公开属性及上文注明的本地 Slider 选项，未复刻未授权 Pro 代码；正式基线与原型分开。
- [x] 状态恢复、长名称、金额混排、未知不等于零，超额不被改写为正常读数。
- [x] 鼠标与键盘操作、详情焦点返回、复制和下载、输入不被全局快捷键抢走。
- [x] 390 / 768 / 1024 / 1440px 视口、深浅主题、单色与服务色、减少动态效果；另检查 360px 长列表。
- [x] 原型图形与滑块读数立即更新，不对额度数字或填充做追赶动画；Arc 控件其余反馈保留自带的减弱动态效果支持。

有意保留的原型例外：页面是纯客户端入口，不支持服务器渲染；仅中文，不是五语言正式发布。字号和几何刻度可独立调节，不完全固定为 Arc 默认字号；未知使用数值缺省符号，不是文案中的破折号。外部五方向切换器严格沿用探索规范，其固定颜色、尺寸、阴影、焦点样式和 28px 点击高度不参与候选设计；其余产品控件按项目 Arc 规则。官方 Arc 控件内部的渐变是裁切蒙版，不是装饰背景。

浏览器触屏模拟只证明 Chromium 模拟环境下的操作；没有实测真机、VoiceOver、macOS WebKit 或原生 Tauri 窗口，不宣称完整无障碍认证。原型没有接入真实账号或更新发布。正式采用前还要处理真实数据、五语言与各平台验收。
