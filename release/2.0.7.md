# TokenPlan 2.0.7

- 修复新增账号未初始化菜单栏用量指标的问题，三个系统按账号独立保存默认选择；保留用户主动取消全部指标的设置，不因重启、账号重连或新增其他账号而恢复。
- 完善“仅显示图标”状态：菜单栏右键菜单区分未选择指标与暂无用量数据；账号设置增加明确提示和“显示首项用量”按钮，方便恢复已有账号的用量显示。
- 为订阅服务的 Logo、正常用量进度和趋势线增加稳定的识别色，适配浅色与深色外观，并保留高用量的黄色、红色预警。
- 完善手动刷新反馈：显示旋转动画及刷新状态、防止重复请求，区分用量更新、暂无新数据、部分失败、限流等提醒；支持减少动画设置。
- 同步 macOS、Windows、Linux，重新打包三平台安装包，保留 macOS 1.0.12 经典版下载。

## 更新说明

2.x 用户可通过“检查更新”升级；Linux 应用内自动更新使用 AppImage，DEB 用户请下载安装新版 DEB。

对于旧版已经没有菜单栏指标的账号，因无法可靠区分历史遗漏与主动取消，本次升级不会强行改变其设置。进入该账号的“设置”，点击“显示首项用量”，或自行开启 5h、1w 等指标的“菜单栏”开关即可恢复。无需重新登录账号。
