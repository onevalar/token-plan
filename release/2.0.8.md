# TokenPlan 2.0.8

- 修复“点击刷新提示已刷新，但额度数据过一会儿才更新”的问题：点击刷新按钮、⌘R 或卡片上的“重试”现在一定会向服务重新取数；重启后的第一次刷新也一定取数；定时刷新不会再因为刚手动刷新过而被跳过。
- 刷新按钮只有在确实取到新数据时才显示“已刷新”；没有取到时显示“未刷新”，并提示稍后再试。
- 新增“添加账号”流程：可添加与其他账号两个标签，一键添加已检测到的账号；备注默认收起，移除账号单独放在页面底部。
- 出错的服务卡片提供下一步按钮（重试、重新登录、设置 API 密钥、查看详情）；首页账号增加设置快捷入口；首次使用有欢迎提示，用量接近上限时提示开启提醒。
- 智谱 Z.ai 与 MiniMax 在密钥无效时会明确提示“密钥被拒绝”。
- “关于”页增加项目链接与致谢；设置页的菜单栏账号列表默认折叠。
- 同步 macOS、Windows、Linux，重新打包三平台安装包。

## 更新说明

2.x 用户可通过“检查更新”升级；Linux 应用内自动更新使用 AppImage，DEB 用户请下载安装新版 DEB。
