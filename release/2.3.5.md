# TokenPlan 2.3.5

- 用量样式「横条」新增「底纹横条」：已用部分为实心色，未用部分为底纹，交界处底纹逐渐变密、融入实心色。
- 底纹横条提供三种版式：全幅卡片、半幅横条、横条；底纹类别可选像素点阵、竖线、圆点网点、斜线、纯色或每项不同；底纹颜色可跟随服务商颜色，或选择蓝、绿、橙、紫。
- 打开首页时用量条从零填充到当前读数；刷新后读数变化时平滑过渡到新位置，不再突变。系统开启“减少动态效果”时直接显示读数。
- 原「整行底色」并入底纹横条的全幅卡片，已保存的选择保持原有外观；全幅卡片高度更紧凑，用量样式中不再显示“已用 / 剩余”文字。
- 同步 macOS、Windows、Linux 界面及五种语言，重新构建安装包和签名更新文件。

## 更新说明

2.x 用户可在应用内检查更新，或下载安装新版。Linux DEB 用户请下载安装新版安装包。
macOS 1.0.12 经典版继续保留下载。本机正式版不自动安装本次更新。
