# TokenPlan 1.0.11

- 新增 Claude、Codex「移除账号」功能：可在账号详情的设置中移除账号，重启或自动扫描后不再重新添加；不会退出命令行工具的登录，也不会删除已保存的用量历史。macOS、Windows、Linux 同步支持。
- 修复菜单栏账号编号不连续的问题：按实际显示的账号顺序从 1 开始连续编号，仅显示一个账号时不标编号；环形和百分比模式保持一致。
- 修复 Claude 切换账号后显示为“Personal”的问题：保留已知邮箱，并使用账号资料中的邮箱更新首页、详情和菜单栏设置，订阅等级单独显示。

升级说明：更新后刷新 Claude 即可更新邮箱显示。临时不用的账号仍可隐藏；不再需要的账号可进入详情 → 设置 → 移除账号。macOS 可通过“检查更新”升级；Windows / Linux 1.0.6 及更新版本可通过应用内更新下载安装包。Windows / Linux 1.0.5 及更早版本需从本仓库手动下载安装新版一次。
