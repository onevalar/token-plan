# TokenPlan 2.3.4

- 用量统计新增显示设置，支持模块开关、拖动排序和样式切换；使用活动可选每日柱形、热力日历或折叠色带，来源构成可选列表或树图，额度变化可选燃尽线或采样记录。
- 图表与显示设置仅用于最近 30 天；今天、昨天保留汇总和每日明细。日历支持悬停或键盘聚焦查看精确读数，统计区域增加清晰标题。
- 额度曲线按账号和指标展示实际采样，缺失数据不补造；三平台在本机保存成功刷新的额度采样，无法恢复此前未记录的历史。
- 优化单环的读数分组与间距、环绕边框的周期及倒计时对齐，修复 API 密钥删除按钮文字溢出。
- 同步 macOS、Windows、Linux 界面及五种语言，重新构建安装包和签名更新文件。

## 更新说明

2.x 用户可在应用内检查更新，或下载安装新版。Linux DEB 用户请下载安装新版安装包。
macOS 1.0.12 经典版继续保留下载。本机正式版不自动安装本次更新。
