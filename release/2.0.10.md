# TokenPlan 2.0.10

- 优化首页和用量详情的额度排列：5h、1w、30d 等周期在固定窄列中左对齐，倒计时右对齐，沙漏放在时间右侧并缩小间距。
- 模型或额度名称改为紧贴用量条的小标注，不再增加额度行高度；长名称以省略号显示，完整名称仍可在账号设置中查看。
- 调整首页文字层级：服务名称和用于区分多账号的账号信息保持清晰，套餐、单账号邮箱、百分比和倒计时更加克制。
- 用量条在已用不足 80% 时保持服务品牌色；已用达到 80%（或剩余降至 20%）时，用量条统一转红，百分比使用较柔和的红色。此显示规则不改变用户设置的通知提醒阈值。
- 无数据的百分比额度保留空用量条和状态文字，不误报额度不足；未知周期不会从名称中猜测。适用于 macOS、Windows 和 Linux 的 2.x 界面。

## 更新说明

2.x 用户可通过“检查更新”升级；Linux 应用内自动更新使用 AppImage，DEB 用户请下载安装新版 DEB。

本次更新不需要重新添加账号或调整现有设置。原生 macOS 1.x 经典版保持冻结，不包含这些改动。
