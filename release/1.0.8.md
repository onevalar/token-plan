# TokenPlan 1.0.8

- 新增 Antigravity Argon 独立每周额度监控，macOS、Windows 和 Linux 同步支持；按服务端返回的额度和重置时间显示，不虚构五小时额度。
- 修复 Antigravity 旧请求遗漏 Argon 额度的问题，避免将 Argon 错误合并到 Gemini 五小时额度。Mac 默认在详情中启用“Argon 每周”，可自行调整到首页或菜单栏。
- 移除 Codex 费用估算中的“备用模型”设置；未知定价模型不再由用户指定其他模型代算。

升级说明：macOS 可通过“检查更新”升级；Windows / Linux 1.0.6 及更新版本可通过应用内更新下载安装包。Windows / Linux 1.0.5 及更早版本需从本仓库手动下载安装新版一次。
