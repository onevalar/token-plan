# TokenPlan 1.0.6

- 补齐 Windows、Linux 的 Claude 和 Codex 认证续期，减少登录过期导致的额度读取失败，并保护账号切换时的凭据。
- 区分权限拒绝、超时、DNS、证书和代理错误，增加不含敏感凭据的网络诊断；Codex 附加信息失败不再影响已取得的额度。
- TokenPlan 正式开源，三个系统的安装包及后续自动更新迁移到 onevalar/token-plan 仓库。
- 更新应用内项目、反馈、隐私与许可证链接，保留透明图标打包校验。

升级说明：macOS 可通过“检查更新”升级。Windows / Linux 1.0.5 及更早版本需要从本仓库手动下载安装 1.0.6 一次，之后使用新的更新地址。
