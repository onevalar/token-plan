# TokenPlan 2.1.0

- 主页现在提供八种可选用量样式：横条、独立仪表、百分格、紧凑环形、额度刻度尺、独立同心环、醒目数字和分段额度条。在“通用设置 → 主页用量样式”中切换，默认仍为横条，选择保存在本机。
- 各种样式保留独立的账号与额度读数、已用或剩余模式、重置时间和额度告警。缺失数据不会变成零，超额读数不会被截成 100%；切换样式不改变用量数据、首页隐藏规则或菜单栏设置。
- 详情页的余额与权益支持按需展开到期日期，收起后仍显示余额或次数；没有到期明细的项目保持直接显示，不增加空的展开操作。
- 每日记录中的模型明细改为构成环形，保留准确的 token 数量、费用和模型细分。未归类记录保留在总数中，未知费用不会显示为零；数据无法形成可靠占比或非零部分超过六个时，显示原明细列表和原因。
- 历史汇总、每日记录布局和账号资料保持原样。新样式支持英语、简体中文、繁体中文、日语和韩语，以及浅色和深色外观。
- 优化额度名称与倒计时的排列，修复百分格在窄窗口中的空间不足问题；从菜单进入“检查更新”时立即检查，无需再点击一次。

## 更新说明

2.x 用户可通过“检查更新”升级；Linux 应用内自动更新使用 AppImage，DEB 用户请下载安装新版 DEB。

本次发布适用于 macOS、Windows 和 Linux 的 2.x 界面。原生 macOS 1.x 经典版保持冻结，不包含这些改动。
