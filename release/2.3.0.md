# TokenPlan 2.3.0

- 账号详情取消两个标签页，改为查看与编辑切换。“编辑首页显示”“添加备注”“移除账号”统一为整行操作；显示内容、排列顺序和账号样式在点击确定后保存，取消则保留原配置。
- 用量样式支持“全局统一”和“按账号自定义”。默认使用横条；自定义时每个账号独立选择样式，同一服务的多个账号也可不同。切回统一模式会保留自定义选择。
- 订阅管理集中处理显示、隐藏、排序、添加和移除账号。账号隐藏后仍保留在列表中，不再需要重新添加；菜单顺序统一为通用设置、订阅管理、用量统计，并保留检查更新入口。
- Claude、Codex 添加账号时可创建独立配置目录和待登录记录，继续使用官方终端登录；中途退出后可在原目录继续。支持连接已有目录，检测结果按目录与账号身份匹配，减少默认目录切换账号造成的连接混淆。不会自动复制或迁移现有登录凭据。
- 账号与首页显示内容支持拖动排序：整行跟随指针、其他条目自动让位，松手后落位；支持长列表自动滚动、Esc 取消、键盘上下调整和减少动态效果设置。
- 精简通用设置：用量样式独立分组，通知开启后展开具体选项，快捷键采用紧凑录制与删除操作。macOS 菜单栏设置整理图标位置、账号开关和指标加减操作。
- Windows 托盘左键单击显示首页、右键单击显示菜单；Linux 使用桌面环境支持的左键激活与右键菜单。可取得托盘位置时，首页在图标附近显示并适配所在屏幕；没有有效位置时，在当前屏幕居中。显示时恢复窗口并请求置顶和焦点。
- macOS、Windows、Linux 同步上述账号、设置与拖动交互，并重新构建三个系统的安装包及更新文件。

## 更新说明

2.x 用户可通过“检查更新”升级。Linux 应用内自动更新使用 AppImage；DEB 用户请下载安装新版 DEB。现有账号、配置和本地历史继续保留。较早版本未记录的隐藏账号，可在添加账号中重新启用一次，之后隐藏会保留在订阅管理中。

Linux 左右键行为、窗口位置和置顶仍受 GNOME/KDE 托盘扩展及窗口管理器限制：部分环境会让左键也打开菜单，可通过“显示主页面”进入首页。

macOS 1.0.12 经典版继续保留下载并维持冻结。本次发布不会替换本机已安装的正式版，由用户自行检查更新。
