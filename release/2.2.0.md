# TokenPlan 2.2.0

- 重新整理通用设置、账号管理和账号设置：首页用量样式改为带缩略图的选择面板；显示或隐藏账号及排序统一在账号管理中操作；macOS 菜单栏预览、账号开关和最多三项指标选择集中在通用设置中。
- 账号设置保留首页指标、备注、密钥与移除功能，提供跳转通用设置的入口；服务详情出错时增加重试或设置 API 密钥按钮。“移除账号”使用整行居中按钮，并保留二次确认。
- 修复用量历史模型和细分项金额出现长小数的问题，统一显示两位小数；优化每日记录卡片间隔与内容边距。
- 修复样式选择面板在英文、日文等语言下的长标签溢出，适配浅色、深色外观。
- Windows、Linux 托盘改为仅显示透明的 TokenPlan 软件图标，移除用量图标、对应设置及首页顶部的重复指标；macOS 保留菜单栏环形、百分比、多账号与三项指标功能。
- 托盘菜单简化为“显示主页面”和“退出 TokenPlan”；显示首页时恢复窗口、置顶并请求焦点。Windows 支持双击直接打开首页。
- 修复 Windows/Linux Antigravity 额度数据漏传周期的问题，正确显示 5h、1w、Argon 周额度及服务实际返回的重置时间。
- 优化首页双环配对：相邻且周期不同的额度可以成对显示，新增第三项额度不再使全部指标退回单环；各项读数保持独立。

## 更新说明

2.x 用户可通过“检查更新”升级。Linux 应用内自动更新使用 AppImage；DEB 用户请下载安装新版 DEB。账号、登录和本地历史继续保留。

Windows/Linux 不再提供托盘用量显示；旧的指标选择会保留在配置中，但不影响软件图标。Linux 的单击菜单由 GNOME/KDE 等桌面环境提供，SNI 接口不提供独立双击事件，因此 Linux 不保证双击直达首页。窗口置顶及焦点请求仍受桌面窗口管理器规则约束。

macOS 1.0.12 经典版继续保留下载并维持冻结，本次更新仅适用于 Tauri 版本。
