# TokenPlan 2.3.1

- 精简关于页面：移除项目主页、更新说明、反馈问题和许可证跳转，以及来源说明。保留应用图标、名称、版本和“不发送任何统计或崩溃报告”的隐私文案，调整文字层级和间距，适配浅色、深色及五种语言。
- 修复 macOS 外接显示器的菜单栏窗口定位：使用原生屏幕坐标，在点击图标的显示器上展开窗口，避免不同缩放比例导致窗口跑到笔记本屏幕。内容高度变化时保持菜单栏附近的位置，并限制在屏幕可用范围内。
- 重新构建 macOS、Windows、Linux 安装包及更新文件；三个系统同步关于页面调整。

2.x 用户可通过“检查更新”升级。Linux 应用内更新使用 AppImage；DEB 用户请下载安装新版 DEB。账号、配置和本地历史继续保留。
