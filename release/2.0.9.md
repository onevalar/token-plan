# TokenPlan 2.0.9

- 首页移除鼠标悬停时出现的账号设置按钮。点击账号名称或箭头统一进入用量详情，设置仍可在详情页的“设置”标签中找到，减少相邻按钮误触。
- “账号”调整为“账号管理”。关闭首页显示后，账号仍保留在管理列表中，重新启动应用后也可以直接在这里恢复显示。
- 添加账号改为先选择服务，再查看对应的连接方式；添加成功后返回账号管理，需要 API 密钥的服务会先进入设置页面。
- 更多菜单分为三个区域：账号管理、用量历史与通用设置；检查更新与关于；退出。移除与账号管理重复的添加账号菜单入口。
- 全部账号隐藏时，首页提供进入账号管理、恢复显示的入口，不再提示没有账号。
- 同步更新五种语言的界面文案，适用于 macOS、Windows 和 Linux 的 2.x 界面。

## 更新说明

2.x 用户可通过“检查更新”升级；Linux 应用内自动更新使用 AppImage，DEB 用户请下载安装新版 DEB。

旧版本没有单独记录“已添加但隐藏”的状态。升级前已经隐藏的账号，需要从“添加账号”重新添加一次；之后关闭显示会将账号保留在管理列表中。
