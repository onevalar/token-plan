# TokenPlan 1.0.1

- 发布 macOS、Windows 和 Linux 安装包；macOS 正式版接入签名自动更新。
- 支持 Claude 独立配置目录多账号识别，简化账号邮箱和订阅等级展示。
- 修复菜单栏账号重复开关、排序不一致，以及百分比模式遗漏未勾选指标的账号。
- 改进设置、订阅详情、关于与托盘交互，修复 Antigravity 用量查询及登录状态误判。

macOS：15 或更高版本，支持 Apple Silicon / Intel，已签名并公证。
Windows：x64。Linux：Debian / Ubuntu x64。
Windows/Linux 使用托盘菜单摘要，尚未提供 macOS 多圆环图标。
