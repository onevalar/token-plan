# TokenPlan 2.3.3

- 订阅的首页显示、指标顺序和用量样式现在修改后立即保存，无需再次确认；账号详情中的当前额度同步使用所选样式。
- 优化首页用量样式的布局与读数展示，整理订阅详情中的备注、API Key 状态及相关操作。
- 新版本提醒改为首页刷新按钮旁的紧凑入口，支持跳过当前版本；仍可在更新页面手动安装，后续新版本会再次提醒。
- 同步五种语言，并优化三平台发布检查与构建缓存；安装包仍须通过回归检查及各平台发布验证后才会公开。
